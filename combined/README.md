# 🔗 Combined Exercises

Cross-track exercises that force you to use **two or three** of Python, SQL, and Linux together — because real engineering never uses one in isolation. Each exercise states which lessons it assumes so you don't attempt it too early.

| # | Exercise | Tracks | Assumes | Status |
|---|----------|--------|---------|--------|
| 01 | [Log-to-Database Mini-Pipeline](exercise-01-log-to-db-pipeline.md) | Linux + Python + SQL | Linux L1–3, Python L1–3, SQL L1–3 | ✅ |
| 02 | _CSV ingest + validation report_ | Python + SQL | Python L1–5, SQL L1–4 | ⬜ |
| 03 | _Cron-scheduled backup + restore check_ | Linux + SQL | Linux L1–7, SQL L1, L14 | ⬜ |

More will be added as the tracks progress. Do these after the listed lessons, on a feature branch, with a PR (Git/GitHub practice).
