# 🏗️ Capstone Projects

Ten production-grade projects to build **after** completing the 45 lessons. Each combines Python, SQL, and/or Linux to simulate real engineering work. Build them on branches, open PRs against yourself, and treat them like work you'd ship.

Every capstone guide includes: Project overview · Business problem · Architecture diagram (Mermaid) · Requirements (functional + non-functional) · Folder structure · Step-by-step implementation guide · Production considerations · Security considerations · Performance improvements · Testing strategy · Common mistakes · Extensions for advanced learners · Interview discussion points · What a senior engineer would improve.
