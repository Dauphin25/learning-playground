# 🐧 Linux Track

Linux from the shell up, aimed at the **DevOps / platform engineer / Linux developer** starting line. Heavy on the command line, processes, networking, and the system internals that make you dangerous in production.

**Target level by the end:** comfortable operating a Linux server — permissions, processes, systemd, networking, storage, troubleshooting, hardening — and scripting real automation in Bash.
