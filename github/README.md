# 🌳 Git & GitHub Mastery

A secondary track to master Git and GitHub *while* building this repo — so the version-control skill is earned through real use, not memorized. Practice each topic on this very repository: branch per lesson, open PRs against yourself, review your own diffs, tag releases.

## Suggested progression

| # | Topic | Status |
|---|-------|--------|
| 01 | Git mental model — the three trees, commits as snapshots, the DAG | ⬜ |
| 02 | Branching, merging & fast-forward vs. merge commits | ⬜ |
| 03 | Rebase, interactive rebase & a clean history | ⬜ |
| 04 | Remotes, fetch/pull/push & tracking branches | ⬜ |
| 05 | Pull requests, code review & protected branches | ⬜ |
| 06 | Resolving conflicts confidently | ⬜ |
| 07 | Undoing things — reset, revert, restore, reflog | ⬜ |
| 08 | Tags, releases & semantic versioning | ⬜ |
| 09 | `.gitignore`, hooks & commit hygiene (Conventional Commits) | ⬜ |
| 10 | GitHub Actions — CI for the lessons' code | ⬜ |

## Practice workflow for this repo
1. `git switch -c lesson/python-04` — a branch per lesson or exercise.
2. Do the work; commit in small, meaningful steps.
3. Push and open a PR; read your own diff critically (or use `/code-review`).
4. Merge, then tag milestones (e.g., `python-track-complete`).

> The goal: by the time the 45 lessons are done, Git is muscle memory and your commit history tells a clean story.
