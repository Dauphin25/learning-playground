# learning-playground

A personal **6-month curriculum** to master **Python, SQL, and Linux** — independently and together — and go from Application Support to a strong **junior+/mid-level engineer** ready for data engineering, DevOps/platform engineering, and Python backend work.

> This repository is to learn Python, Linux and SQL, together and independently.

## How it's organized

| Track | Folder | Goal |
|-------|--------|------|
| 🐍 Python | [`python/`](python/) | Generic Python cemented toward data engineering, FastAPI, and data science |
| 🗄️ SQL | [`sql/`](sql/) | PostgreSQL confidence toward data engineering, Kafka & streaming |
| 🐧 Linux | [`linux/`](linux/) | Foundation for DevOps, platform engineering, and Linux development |
| 🔗 Combined | [`combined/`](combined/) | Exercises that combine 2–3 of the tracks |
| 🏗️ Capstones | [`capstones/`](capstones/) | 10 production-grade projects built after the 45 lessons |
| 🌳 Git/GitHub | [`github/`](github/) | Master Git & GitHub while building this repo |

Each track has 15 lessons. Every lesson is a self-contained ~2-hour deep dive with theory, official-doc quotes, real-world examples, a **How This Is Used In Production** section, best practices, interview Q&A, and Easy/Medium/Hard homework. See [`CLAUDE.md`](CLAUDE.md) for the exact lesson format.

## How to use this repo

1. Pick a track and work lessons in order (`lesson-01`, `lesson-02`, …).
2. Do the homework before reading any solution.
3. After every few lessons, do a `combined/` exercise to connect the tracks.
4. After all 45 lessons, build the capstones.
5. Practice Git/GitHub the whole way: branch per lesson, open PRs, review your own diffs, tag releases.
